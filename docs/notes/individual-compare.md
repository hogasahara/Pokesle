# 個体比較の一般則

最終確認: 2026-09-11。根拠: pokesleep-tool の計算 (`tools/calc/compare.ts`)

## ツールの使い方で間違えやすい点

- スキルレベルは「ゲーム内の表示値」で渡す。スキルレベルアップ M/S を持つ個体は、その分だけ表示値が高い状態で比較する (ツールは新規作成時に自動加算しない)
- 「日中タップなし」設定はスキル回収も 0 扱いになるので比較に使わない。3h ごと (既定) と 8h ごとで見る

## 分かっていること

- 最大所持数系サブスキルとげんき回復ボーナスは、3h ごとにタップする運用ではほぼ価値がない (溢れないため)。タップ間隔が長いほど価値が上がる
- スキル得意ポケモンは「スキル確率アップ M + スキルレベルアップ S」のように発動回数とレベルを直接上げる構成が、既定運用では所持数系より 2 割前後強い
- 両者がスキル Lv 最大 (6) に到達済みだとスキルレベルアップ S は死にサブになり、タップ間隔が長い運用では所持数系が逆転しうる

## 事例

### ラティオス Lv50 (2026-09-11)

- A: 食材確率アップ M / スキル確率アップ M / スキルレベルアップ S + いじっぱり
- B: 最大所持数アップ S / 最大所持数アップ M / げんき回復ボーナス + しんちょう
- スキルのタネ同数 (素 Lv3 → A 表示 Lv4, B 表示 Lv3): 3h タップで A が 22% 有利、8h タップで A が 7% 有利 (好物有無で変わらず)
- 表示 Lv が同じ場合: 3h タップで A が 12% 有利、8h タップでは B が 3〜7% 有利
- 結論: 基本は A。B が上回るのは「日中ほとんどタップしない」かつ「両方スキル Lv6 まで育てた」場合のみ
- 理論値最強との比較 (同じ表示スキル Lv、3h タップ、好物なし): 最強E 構成 (きのみの数S / スピードM / 所持数L + ゆうかん) は Lv3 で 32,418、Lv6 で 41,331。A はその 71〜79%、B は 64〜71%。スキル回数は最強E 2.93 回/日で A (3.08) より少なく、回数最強構成 (スキル確率M / S / スピードM + しんちょう) は 3.99 回/日で A の 1.3 倍、エナジーも A より 14〜18% 上

## 厳選補助ツール rate.ts (2026-09-12)

- `tools/calc/rate.ts` は個体 1 体を、同じ Lv・条件でサブスキル全 17 種 × せいかく (× 食材構成) を総当たりした母集団と比べる
- 出す指標: 合計E、きのみE、スキル発動回数、スキルE、食材合計、食材ごとの個数。得意分野で主指標を決める (きのみ→きのみE、スキル→発動回数、食材→指定食材の個数)
- 「これより上を引く確率」の重みに使うサブスキル出現率 (金 2.3% / 青 5.7% / 白 12.5%) は Web 検索結果の要約に出てきた通説値。Game8 のサブスキル記事には数値の記載がなく、Wiki* の「検証/サブスキル抽選確率」ページは 403 で確認できていない。合計がほぼ 100% になるので整合的だが、要再確認
- スキルレベルは表示値で渡す。ツール内部でサブスキル分を引いた素のレベルを求め、母集団側は各構成のスキルレベルアップを加算して比較する
- 食材型は 1 匹あたり 40 秒前後かかる (食材構成 6 通り分)
